# 即時戰略遊戲開發企劃書（開發代號：Iron Conflict）

這是一份基於Web技術的即時戰略（RTS）遊戲開發企劃書，旨在打造一款內容豐富、可透過GitHub Pages直接遊玩的網頁遊戲。

## 一、遊戲定位與目標
- **類型**：即時戰略（RTS）
- **風格**：寫實軍事 × 資源經營 × 陣營對抗
- **平台**：網頁瀏覽器（PC），為滑鼠與鍵盤操作進行優化
- **目標**：實現一個功能完整、可部署在GitHub Pages上的純前端RTS遊戲。

## 二、核心玩法設計
### 1. 遊戲核心循環
遊戲的核心體驗圍繞以下循環：
`資源採集 → 基地建設 → 軍隊訓練 → 戰術操作 → 戰場壓制`

### 2. 陣營與單位設計
遊戲初期設計兩大陣營，未來可擴充。每個陣營具有獨特的優勢與劣勢：

| 分類 | 陣營A（機械優勢） | 陣營B（科技優勢） |
| :--- | :--- | :--- |
| **資源開採效率** | 普通 | 較快 |
| **地面部隊** | 耐久度高但移動緩慢 | 較脆弱但靈活 |
| **空中部隊** | 攻擊型無人機、重型轟炸機 | 快速偵查機、高空精準打擊 |
| **特殊能力** | 坦克加速推進 | 雷達干擾、間諜滲透 |

## 三、系統設計細節
### 1. 資源系統
- **礦石**：主要資源，用於建造建築和訓練單位。
- **能源**：次要資源，維持高級建築運作與啟用特殊單位（如雷達、Tesla防禦塔）。
- **人口上限**：由「指揮中心」或「控制中心」等特定建築提供，限制玩家可擁有的單位總數。

### 2. 建築類型
| 分類 | 功能說明 |
| :--- | :--- |
| **指揮中心** | 核心建築，被摧毀則遊戲失敗。提供基礎人口。 |
| **發電廠** | 提供能源，是運作高級建築和單位的前提。 |
| **採礦場/精煉廠** | 產出礦石，是經濟的基礎。 |
| **兵營** | 訓練步兵單位。 |
| **軍工廠** | 生產地面載具（如坦克、採礦車）。 |
| **機場** | 建造和部署空中單位。 |
| **防禦設施** | 機槍塔、電磁塔、地雷等自動防禦單位。 |

### 3. 單位類型（示意）
| 類型 | 單位名稱 | 功能 |
| :--- | :--- | :--- |
| **步兵** | 火箭兵 | 基礎對空單位。 |
| **步兵** | 工程師 | 可修復受損建築或佔領中立/敵方建築。 |
| **載具** | 輕型坦克 | 移動速度快，適合偵查與騷擾。 |
| **載具** | 重型坦克 | 高耐久、高傷害，是正面作戰的主力。 |
| **載具** | 採礦車 | 自動採集礦石並運回精煉廠。 |
| **空軍** | 偵查機 | 快速揭開戰爭迷霧，提供戰場視野。 |
| **空軍** | 轟炸機 | 對地面目標進行毀滅性打擊。 |

## 四、遊戲流程與操作
### 1. 遊戲流程
1.  玩家選擇陣營和起始點。
2.  開局擁有一座指揮中心和少量基礎單位（如工程車）。
3.  建立基礎設施：發電廠 → 採礦場。
4.  擴展軍隊生產建築（兵營、軍工廠）和防禦體系。
5.  透過偵查與擴張來控制地圖資源，建立分基地。
6.  執行多樣化的戰術行動（偷襲、正面壓制、資源搶奪）。
7.  最終目標：摧毀所有敵方的指揮中心。

### 2. 控制方式
- **滑鼠左鍵**：選取單位或建築。支援點選和框選。
- **滑鼠右鍵**：對選取的單位下達指令（移動、攻擊、採集、修復）。
- **鍵盤快捷鍵**：為建築和單位訓練設定熱鍵（如 `B` 鍵開啟建築選單，`V` 鍵訓練步兵）。支援單位編隊（`Ctrl + 1-9`）。
